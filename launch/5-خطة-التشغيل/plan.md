## 1. السيرفر أونلاين خطوة بخطوة (Railway)

النظام كله (الموقع، تطبيق الزبون، المطعم، المندوب، صاحب الشركة) بيشتغل من سيرفر واحد على Railway. التكلفة حوالي 5$ بالشهر (خطة Hobby، معها 5$ استخدام) + التخزين 0.15$ لكل GB ([المصدر](https://docs.railway.com/pricing/plans.md)). الكود جاهز على [github.com/abood-19/KARTO](https://github.com/abood-19/KARTO).

### أ) إنشاء الحساب والسيرفر (15 دقيقة)

1. افتح [railway.com](https://railway.com) ← **Login** ← **Continue with GitHub** (حساب abood-19).
2. فعّل الخطة: **Account Settings ← Plans ← Hobby** وحط بطاقة Visa.
3. افتح [railway.com/new](https://railway.com/new) ← **Deploy from GitHub repo** ← اختار **KARTO** ← **Deploy Now**.
4. Railway بيلاقي الـ `Dockerfile` لحاله وبيبني السيرفر (2–4 دقائق).
5. اضغط على الخدمة (المربع KARTO) ← تبويب **Variables** ← **New Variable** وضيف:
   - `KARTO_DATA` = `/data`
   - `TZ` = `Asia/Tashkent`
6. نفس الخدمة ← كليك يمين على المربع أو **Settings** ← **Attach Volume** ← Mount path = `/data` ← Add. (بدونه البيانات بتنمسح مع كل تحديث.)
7. **Settings ← Networking ← Generate Domain** ← بيعطيك رابط مثل `karto-production.up.railway.app`.
8. تبويب **Deployments** ← آخر Deploy ← **View Logs**. انسخ واحفظ بمكان آمن:
   - رابط صاحب الشركة السري: `/office-xxxxxxxxxx/`
   - **First admin setup key** (رمز التجهيز)

### ب) أول تشغيل (10 دقائق)

1. افتح `https://رابطك/office-xxxx/` ← اكتب رمز التجهيز + اسم مستخدم + كلمة سر قوية.
2. لوحة صاحب الشركة ← **الموظفين**: شوف أرقام PIN الأولى، غيّرها، وضيف كل موظف ومندوب باسمه.
3. **المنيو والأسعار**: راجع الأسعار. **المخزون**: حط الكميات الحقيقية.
4. **🔒 الأقسام**: افتح الأقسام اللي بدك تشغلها.

### ج) أجهزة المحل

| الجهاز | الرابط | مين بيثبته |
| --- | --- | --- |
| تابلت الكاشير | `رابطك/restaurant/` ← PIN الكاشير | الكاشير |
| تابلت المطبخ | `رابطك/restaurant/` ← PIN المطبخ | المطبخ |
| شاشة العرض (TV) | `رابطك/restaurant/` ← PIN المدير ← تثبيت: شاشة العرض | مدير الفرع |
| موبايل المندوب | `رابطك/courier/` | المندوب |
| موبايل/تابلت الحضور | `رابطك/restaurant/` ← تثبيت: الموظفين | مدير الفرع |

على كل جهاز: قائمة المتصفح ← **إضافة للشاشة الرئيسية** (Add to Home screen) عشان يفتح كتطبيق.

### د) الدومين (karto.uz)

1. ادخل على [cctld.uz](https://cctld.uz) (مركز دومينات .uz) واختار مسجّل معتمد واشتري `karto.uz` (لازم بيانات شخص أو شركة بأوزبكستان).
2. بـ Railway: **Settings ← Networking ← Custom Domain** ← اكتب `karto.uz` ← بيعطيك سجل **CNAME**.
3. بلوحة المسجّل ← DNS ← ضيف الـ CNAME متل ما Railway قال. خلال ساعة بيشتغل مع HTTPS تلقائي.
4. النتيجة: `karto.uz` = الموقع · `karto.uz/app/` = تطبيق الزبون · `karto.uz/restaurant/` = المطعم.

### هـ) استرجاع كلمة السر على تيليغرام

1. افتح [@BotFather](https://t.me/BotFather) ← `/newbot` ← اسم: `KARTO Admin` ← بيعطيك **Token**.
2. Railway ← **Variables** ← `TELEGRAM_BOT_TOKEN` = الـ Token.
3. ابعت أي رسالة للبوت تبعك، وبلوحة صاحب الشركة ← **حسابي** حط رقم الـ Chat ID تبعك بخانة Telegram (بتعرفه من [@userinfobot](https://t.me/userinfobot)).

### و) الدفع والضرائب (بدها أوراق الشركة)

- **Click**: طلب حساب تاجر من [click.uz](https://click.uz) (قسم للأعمال).
- **Payme**: طلب حساب تاجر من [payme.uz](https://payme.uz).
- **الإيصال الضريبي (Online-ККМ)**: محاسب + مزوّد كاشير معتمد من لجنة الضرائب. هاد آخر خطوة، والنظام جاهز يربط فيه.

### ز) أمان ونسخ احتياطية

- رابط صاحب الشركة لا تعطيه لحدا. رمز التجهيز بيبطل بعد أول حساب.
- كل أسبوع: Railway ← Volume ← **Backups** (أو نزّل `karto-db.json`).
- أي تحديث على الكود برفعه على GitHub ← Railway بيحدّث السيرفر لحاله.

**خطوات اختيار المورد:**

1. ابحث بالكلمات اللي بالجداول، وفلتر: **Verified Supplier** + **Trade Assurance** + أكثر من 3 سنين.
2. اختار 3 موردين لكل قطعة، وابعتلهم نفس المواصفات بالضبط (انسخها من هاد الملف).
3. اطلب من كل واحد: سعر FOB وسعر توصيل لطشقند، فيديو مباشر من المصنع، شهادات (CE / Food grade)، ومدة الإنتاج.
4. اطلب **عينات** (التغليف والبهارات والبطاطا) بالشحن السريع قبل الطلب الكبير.
5. ادفع 30% مقدم و 70% بعد الفحص، ودايماً من خلال Trade Assurance.

7. جمّع كل الطلبيات عند **وكيل شحن واحد** بـ Guangzhou أو Yiwu واشحنها مع بعض بشحنة وحدة.

## 9. ترتيب التنفيذ

من اليوم للافتتاح حوالي 8–10 أسابيع. التغليف المطبوع هو الأطول (تصميم + عينة + إنتاج + شحن)، فابدأ فيه أول.

- [ ] **الأسبوع 1:** شغّل السيرفر على Railway (القسم 1) واحجز الدومين karto.uz.
- [ ] **الأسبوع 1:** جهّز ملفات اللوغو (AI/PDF) وابعت طلب عروض أسعار لـ 3 موردين لكل قطعة تغليف (القسم 5).
- [ ] **الأسبوع 1–2:** عروض أسعار المعدات (القسم 2 و 3)، وقرّر: قلاية عادية + شفاط، ولا أوتوماتيكية بدون شفاط.
- [ ] **الأسبوع 2:** اطلب العينات جواً: الكونات، كاسات الصوص، الشاكرات، أكياس العصير، البهارات الـ 7، وكرتونة بطاطا.
- [ ] **الأسبوع 2:** مخلّص جمركي بطشقند يراجع القائمة، واختار وكيل الشحن (القسم 8).
- [ ] **الأسبوع 3:** افحص العينات، جرّب المذاق، واعتمد التصاميم النهائية.
- [ ] **الأسبوع 3:** ادفع المقدم وابدأ الإنتاج (تغليف ومعدات بنفس الوقت).
- [ ] **الأسبوع 3–6:** تجهيز المحل محلياً: كهرباء 380V، مي وصرف، بلاط، فتحة الشفاط، تراخيص الصحة والدفاع المدني.
- [ ] **الأسبوع 4–5:** افتح حساب تاجر Click وPayme، ورتّب الـ Online-ККМ مع المحاسب.
- [ ] **الأسبوع 6–8:** وصول الشحنات والتخليص وتركيب المعدات.
- [ ] **الأسبوع 8:** تدريب الموظفين على النظام، وتثبيت كل جهاز على قسمه، وأسبوع تشغيل تجريبي مع العيلة والأصحاب.
- [ ] **الأسبوع 9–10:** الافتتاح + توزيع الفلايرات + عرض الافتتاح من زر «📣 العروض».
