# KARTO — كيف تدخل كل قسم

## 1) نسخة التجربة (رابط المعاينة / GitHub Pages)
كل شي مفتوح بدون كلمات سر. لو طلب منك:

| مين | الدخول |
| --- | --- |
| صاحب الشركة | اسم المستخدم `demo` · كلمة السر `karto2026` |
| مدير الفرع | PIN `2222` |
| الكاشير | PIN `3333` |
| المطبخ | PIN `4444` |
| المندوب | PIN `5555` |

## 2) النظام الحقيقي (على السيرفر Railway)
أول ما تشغّل السيرفر بيعمل 3 ملفات سرية بمجلد `data/`:

| الملف | شو فيه |
| --- | --- |
| `data/admin-path.txt` | الرابط السري للوحة صاحب الشركة، مثلاً `office-3f9a1c2b7e` → بتفتح `https://دومينك/office-3f9a1c2b7e/` |
| `data/setup-key.txt` | رمز التجهيز (8 أحرف). بتحتاجه مرة وحدة بس، أول دخول |
| `data/first-pins.txt` | أرقام PIN الأولى للموظفين (مدير، كاشير، مطبخ، مندوب) |

نفس المعلومات بتطلع كمان بسجل السيرفر (Railway → Deployments → Logs).

### أول دخول لصاحب الشركة
1. افتح الرابط السري.
2. اكتب رمز التجهيز، وكلمة سر جديدة (8 أحرف على الأقل) مرتين، وإيميلك.
3. من «حسابي» اربط تيليغرام، عشان «نسيت كلمة السر» يبعتلك رمز على تيليغرام أو الإيميل.
4. من «الموظفين» غيّر أرقام الـ PIN وأضف أسماء الموظفين الحقيقية.

### أجهزة المطعم
- افتح `https://دومينك/restaurant/` على أي جهاز.
- **مدير الفرع** بيدخل الـ PIN تبعه ← بتبين كل الأقسام ← بيختار «ثبّت هالجهاز على قسم» (كاشير أو مطبخ أو شاشة العرض).
- بعدها الجهاز بيفتح هالقسم بس، وما بيشوف الموظف أي قسم ثاني.
- **الكاشير** بيدخل PIN الكاشير، و**المطبخ** PIN المطبخ.
- **شاشة العرض (TV)** ما بدها PIN، المدير بيثبّتها مرة وحدة.
- لتغيير قسم الجهاز: زر «⇄ تغيير القسم» + PIN المدير.

### الزبائن
- الموقع: `https://دومينك/` (الموقع بس، ما فيه أي رابط للنظام).
- التطبيق: `https://دومينك/app/` أو تطبيق المتجر (مجلد `mobile`).
- المندوب: `https://دومينك/courier/` + PIN المندوب.

### متغيّرات السيرفر (Railway → Variables)
| المتغيّر | لشو |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | بوت تيليغرام لرموز استرجاع كلمة السر (من @BotFather، مجاني) |
| `RESEND_API_KEY` + `MAIL_FROM` | إيميل الاسترجاع (Resend، مجاني لحد 3000 إيميل بالشهر) |
| `ADMIN_PATH` | اختياري: لو بدك تختار الرابط السري بنفسك |
