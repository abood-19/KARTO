# KARTO — Beyond Ordinary Potatoes

3 أنظمة على عقل واحد (سيرفر واحد وقاعدة بيانات وحدة):

| المجلد | النظام | لمين | الدخول |
|---|---|---|---|
| `owner/` | **صاحب الشركة**: تحكم كامل، طلبات وملاحظات مدير الفرع، الحضور بالتلفون والموقع، والنظام كامل (`system.html`) والدليل والمجسم والصور | صاحب الشركة | اسم مستخدم + كلمة سر · رابط سري |
| `restaurant/` | **نظام المطعم** (تطبيق واحد): كاشير · مطبخ · شاشة العرض · توصيل · موظفين · مدير الفرع | جوا المطعم | PIN لكل قسم |
| `app/` | **تطبيق الزبون**: طلب، دفع، تتبع طلبه هو، فاتورة، سجل كل طلباته | الزبائن | — |
| `courier/` | **تطبيق المندوب** (لموبايله) | مندوب التوصيل | PIN |
| `site/` | **موقع الشركة** على دومين خاص | الناس | — |
| `server/` | **العقل**: السيرفر وقاعدة البيانات | — | — |

**أرقام PIN:** أول تشغيل للسيرفر بيعمل أرقام عشوائية سرية بـ `data/first-pins.txt` (مدير الفرع، كاشير، مطبخ، مندوب). غيّرها من لوحة صاحب الشركة ← Xodimlar.
(النسخة بدون سيرفر للمعاينة بس: 2222 · 3333 · 4444 · 5555.)

**نظام المطعم:** `/restaurant/` بيفتح لوحة PIN بس. الكاشير بيفتح الكاشير، المطبخ المطبخ، المندوب التوصيل — وكل جهاز بيضل على قسمه. مدير الفرع بيشوف كل أقسام المطعم وبيثبّت أي جهاز على قسم (مثلاً شاشة العرض). تغيير قسم الجهاز (زر ⇄) بدو PIN مدير الفرع. لوحة صاحب الشركة ما بتبين بالمطعم أبداً — رابطها سري.
صاحب الشركة بيغيّر كل الـ PIN، وبيضيف أي عدد موظفين ومندوبين (كل واحد بـ PIN خاص) من لوحته ← Xodimlar، وبيقفل أو يفتح أي قسم من «🔒 الأقسام».
اللغات: العربية، الأوزبكية، الروسية، الإنجليزية (زر اللغة بكل شاشة).
رقم الطلب من 101 كل يوم · رقم الفاتورة `KARTO-000001` متسلسل دائم.

## 📣 العروض
صاحب الشركة ← «📣 العروض»: عنوان + تفاصيل + سعر + صورة أو فيديو (رفع لحد 80MB، أو رابط YouTube / mp4) + تاريخ انتهاء، ويختار وين ينعرض:
الموقع · تطبيق الزبون · شاشة العرض بالمحل · الكاشير · المطبخ · المندوب · الموظفين · مدير الفرع. بينتشر فوراً بكل الأماكن، وبيقدر يوقفه أو يحذفه بأي وقت.
الفيديوهات بتنحفظ بـ `data/uploads/`. بالديمو (بدون سيرفر) الملف لحد 1.5MB.

## التشغيل
Node.js 20+ بس. ويندوز: دبل كليك `start-karto.bat` — أو `npm start`. الشاشة بتعطيك:
- الموقع `/site/` · نظام المطعم `/restaurant/` · تطبيق الزبون `/app/` · المندوب `/courier/`
- **رابط صاحب الشركة السري** (بـ `data/admin-path.txt`) و**رمز التجهيز** لأول حساب.

أجهزة المحل على نفس الواي فاي: `http://IP-الكمبيوتر:4000/restaurant/` ← «إضافة للشاشة الرئيسية».
للإنترنت: Render / Railway / VPS بالـ `Dockerfile` + دومين وHTTPS. البيانات بـ `data/karto-db.json` (نسخة احتياطية يومية).

## كل نظام لحاله
كل مجلد تطبيق كامل (أيقونة، manifest، sw.js، config.js). إذا استضفته بمكان ثاني، حط عنوان السيرفر بـ `config.js`:
`window.KARTO_API = "https://karto.uz";`

## الأمان
صاحب الشركة: كلمة سر مشفّرة، قفل 15 دقيقة بعد 5 محاولات، رابط سري، استرجاع برمز على تيليغرام (`TELEGRAM_BOT_TOKEN`) أو إيميل (`RESEND_API_KEY`).
الأقسام: كل قسم بيقبل PIN دوره بس، و8 PIN غلط ← قفل 5 دقائق.

## التشغيل الفعلي (نهائي)
النظام الفعلي بيشتغل بالسيرفر (`server/`) — قاعدة البيانات والعروض والفيديوهات كلها عليه، وكل الأجهزة بتتزامن لحظياً.
1. سيرفر على الإنترنت: Railway / Render (مع Disk لمجلد `data/`) أو VPS — بالـ `Dockerfile`، واربط الدومين (مثلاً karto.uz).
2. افتح رابط صاحب الشركة السري (بيطلع بسجل السيرفر) ← اعمل حسابك برمز التجهيز.
3. أجهزة المحل: `https://الدومين/restaurant/` ← «إضافة للشاشة الرئيسية».
4. الزباين: `https://الدومين/` (الموقع) و`/app/` (التطبيق).

## لسا بدها حساباتك
الإيصال الضريبي الرسمي (online-ККМ)، حساب تاجر Click/Payme، دومين وسيرفر.
